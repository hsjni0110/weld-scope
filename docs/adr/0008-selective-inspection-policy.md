# ADR 0008 선택적 정밀 분석 정책과 시간 예산

- 상태: 승인
- 날짜: 2026-11-20
- 관련 단계: S08
- 관련 요구사항: F04, F05
- 승인 근거: 사용자가 S08 실행 계획을 승인하고 구현을 요청했다.
- 구현 검증: ARM64 Release 독립 빌드의 정책 검사와 고정 샘플 8개 통과. [S08 단계 기록](../steps/S08-selective-inspection-policy.md)

## 문제와 제약

불확실한 빠른 점수에만 정밀 분석을 적용한다. 최종 판정, 분석 실패, 시간 예산에 따른 보류의 의미가 호출 경로마다 달라지면 검수와 통합이 어렵다.

## 대안

| 방식 | 검수에 미치는 영향 |
|---|---|
| 독립 C++ 정책과 고정 샘플 콘솔 | 한 계약에서 정밀 호출 수와 시간 경계를 보장한다. |
| 기존 영상 CLI에 직접 연결 | 실제 입력에 연결하기 쉽고, 독립적인 경계 검수에는 별도 점수 입력 경로가 필요하다. |
| 두 개의 순수 판정 함수 | 점수 분류는 짧지만 시간과 호출 횟수 제어가 호출자에게 남는다. |

## 결정과 이유

C++ 정책은 빠른 관측과 정밀 콜백을 받아 정밀 분석을 동기 호출로 최대 한 번 수행한다. 빠른 단계와 정밀 단계의 판정 범위를 각각 설정한다. 두 분석의 시간 합을 양의 마이크로초 예산과 비교하며, 반환 후 초과는 REVIEW다. 빠른 점수가 불확실하면 남은 시간이 양수일 때만 정밀 분석을 시작한다.

PASS·FAIL·REVIEW·ERROR는 최종 판정이다. REANALYZE는 정밀 콜백을 시작할 때 기록하는 경과 상태다. 잘못된 관측과 분석 실패는 ERROR이며, 둘 중 하나와 시간 초과가 함께 있어도 ERROR로 기록한다. 세부 경계와 예는 S08 단계 기록에 둔다.

## 영향

정책은 표준 라이브러리만 사용한다. S04·S07의 영상 계산·출력과 S03의 화면 상태는 해당 단계의 계약을 따른다. 향후 연결부는 단조 시계로 분석 구간을 재고, 관측을 생성할 때 소요 시간을 명시한다. 예상한 분석 오류는 점수 없는 관측으로 전달한다. 시간 초과 확인은 동기 호출이 반환된 뒤 수행한다.

## 검증과 재검토 조건

고정 관측으로 경계의 등호, 시간 소진과 초과, ERROR 우선순위와 콜백 0·1회를 시험한다. 실제 영상 연결과 운영 임계값 동결은 S11에서 검수한다. 강제 중단을 요구하는 시간 계약은 별도로 검수한다.
