# ADR 0013 포트폴리오 앱의 기본 검사기

상태는 승인이다. 사용자가 OPENZDM 연구 결과를 검수하고 최종 모델을 실제 포트폴리오 앱에 적용하도록 요청했다.

## 선택

x64 MFC 파일·폴더 검사는 시작할 때 동결된 연속 보간 모델을 한 번 읽는다. 설정과 가중치의 SHA-256을 확인하며, 누락 또는 불일치가 있으면 해당 모델로 새 검사를 시작할 수 없다. 실행 폴더의 실험 파일 구성에 따라 기본 모델이 달라지는 방식은 같은 앱에서 다른 판정을 내릴 수 있어 폐기했다. 소스 빌드와 일반 배포 ZIP은 동일한 [모델 설정](../../config/pooled-smooth-220.json)을 사용한다.

장비는 설정 ID `pooled-smooth-220-v1`로 기본 모델을 요청한다. 기존 기준 검사·선택적 검사의 명시적인 TCP 요청은 계속 처리한다. 퇴역한 연구 모델은 과거 요청의 입력과 설정 해시를 대조한 뒤 저장된 결과만 재전송한다. 이력 형식과 검사 ID는 [장비·이력 계약](0010-record-device-integration.md)을 따른다.

적용 범위는 포트폴리오다. 비교 결과, 실패 사례와 현장 검증 조건은 [연구 문서](../algorithms/openzdm-false-pass-eda.md)에 기록한다.
