# ADR 0007 국소 대비와 다중 스케일 검사

- 상태: 승인
- 날짜: 2026-11-20
- 관련 단계: S07
- 관련 요구사항: F02, F03, F09
- 승인 근거: 사용자가 2026-11-20에 S07 구현 계획 승인
- 구현 검증: [S07 단계 기록](../steps/S07-improved-inspection.md)

## 문제와 제약

S04의 전역 밝기 비율은 정상 영상의 넓은 어두운 배경을 후보에 포함하고, 불량 영상의 좁은 변화는 놓칠 수 있다. 동일 원본에서 공간적 특징과 추가 계산의 비용을 비교한다. 공식 train은 개발 비교에 사용하며 독립 평가 정책은 ADR 0003을 따른다.

## 대안

| 방식 | 고려 사항 |
|---|---|
| 전역 밝기 정규화 | 영상 간 밝기 차이에 대응하며 영상 내 위치와 연속성은 여전히 반영하기 어렵다. |
| 수평 국소 대비와 다중 스케일 | 같은 행의 밝고 어두운 변화를 후보로 표시하고 계산 범위와 연속성의 영향을 비교할 수 있다. |
| 중앙부 고정 자르기 | 계산 범위는 줄지만 영상별 용접선 위치와 잘려 나가는 후보를 확인해야 한다. |

## 결정과 이유

수평 국소 대비를 빠른 경로에 사용하고, 정밀 경로에는 더 넓은 국소 대비와 후보 연속성을 추가한다. 후보 수를 원본 픽셀 수로 정규화한다. 계산식·시작 설정과 검수 범위는 S07 기록에 둔다.

## 영향

기존 C++ Core와 CLI로 실행하며 S04 기본 경로와 결과 계약은 ADR 0004를 따른다. 사용자 정책에 따른 분석 선택은 S08에서 다룬다. 후보 마스크는 이미지 단위 판정 근거다.

## 검증

손으로 계산 가능한 영상에서 경계값과 다중 스케일 후보를 확인한다. 동일 manifest를 세 경로에서 각각 실행해 오류율, 불량 유출, 정상 오판, 영상 크기별 비용과 재현성을 비교한다.

## 재검토 조건

국소 대비가 오판을 줄이지 못하거나 정밀 분석의 추가 비용에 상응하는 이점이 관찰되지 않으면 실패 사례와 함께 후속 적용을 재검토한다. 독립 평가를 위한 분할·정책 동결은 S11에서 검수한다.
