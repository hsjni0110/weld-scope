# ADR 0014 LightGBM 단일 판정

상태는 승인이다. 사용자가 밝기 기반 추가 검사 제거와 버전 2 구현을 요청했다. 구현과 검수 결과는 판정 계약과 별도로 기록한다.

## 선택

새 파일·폴더·CLI·TCP 검사는 한 모델의 특징 추출과 트리 추론, 폭별 경계 보간을 공유한다. 220개 나무의 가중치와 경계 수치를 유지한다. 정상선 이하와 불량선 이상은 각각 정상과 불량, 그 사이의 점수는 검토 필요다. 분석 시간은 저장하며 판정에는 사용하지 않는다. 132µs는 이전 추가 검사 실험 조건이었다.

설정과 가중치 SHA-256을 검증한다. 설정 누락이나 변조 시 앱에서 새 검사를 시작할 수 없다. 이전 설정에서 신규 검사를 실행하는 경로는 삭제한다. 학습된 모델이 제공하지 않는 픽셀별 후보 표시도 새 화면에서 제거한다.

## 장비와 이력 호환

장비 설정 ID는 `pooled-smooth-220-v2`, 저장 알고리즘 버전은 `openzdm-pooled-smooth-220-v2`다. 이전 ID로 새 요청을 보내면 `CONFIG_UNAVAILABLE`이다. 저장된 요청은 기존 입력 ID와 설정 해시를 대조해 같은 검사 ID와 결과를 반환한다. 서로 다르면 `REQUEST_CONFLICT`를 반환한다. 새 판정은 한 개의 `LIGHTGBM` 분석 기록을 저장한다. 기존 이력의 판정, 점수, 이유, 원본 확인 상태는 그대로 읽는다.

## 근거와 검수

이 결정은 밝기 기반 보조 검사와 시간 초과 보류를 제거해 검사 결과를 점수로만 결정한다. 이전 정책의 실험과 조건은 [알고리즘 연구 기록](../algorithms/openzdm-false-pass-eda.md)에 남긴다. 새 정책의 적합성은 같은 시험 사진에서 놓친 불량, 정상 오판과 검토 건수를 별도로 집계한다. 현장 적용에는 부품과 촬영 배치가 구분되는 별도 시험이 필요하다.
