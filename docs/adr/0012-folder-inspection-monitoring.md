# ADR 0012 폴더 검사와 묶음별 결과 저장

- 상태는 승인이다. 사용자가 [S13 실행 계획](../steps/S13-folder-inspection-monitoring.md) 검수 뒤 진행을 요청했다.
- 관련 요구사항은 F01, F06, F07, F10이다.

## 경계와 선택

폴더의 PNG 상대 경로 목록을 한 번 확정하고, 분석과 저장을 기존 단일 실행 슬롯에서 한 파일씩 수행한다. Windows 기본 폴더 선택기와 기존 MFC 창을 사용한다. 순차 처리는 단일 파일·TCP와 같은 취소 및 저장 재시도 정책을 적용할 수 있다. 병렬 처리와 별도 모니터링 서버에는 추가 큐, 동시 저장 및 전달 상태가 필요하다.

MySQL에 묶음 헤더와 검사 순서의 관계를 추가한다. 별도 연관 테이블을 쓰면 기존 검사 테이블의 행과 API를 그대로 조회할 수 있다. 관계와 검사·분석 시도는 한 트랜잭션으로 저장하며, 저장 확인 후 다음 입력으로 진입한다. 묶음 ID와 순서는 한 실행에서 유일하다. 행 단위 조회는 제한된 페이지로 제공한다.

이력 상세 조회는 [InspectionDetails](../../src/WeldScope.App/InspectionDetails.h)에서 저장 기록과 원본을 읽는다. 폴더 결과라면 저장 당시 설정으로 후보 영상도 복원한다. MFC 창은 백그라운드 조회를 요청하고 반환된 상태에 맞는 문구와 영상을 표시한다.

## 호환 및 검증

기존 단일 파일과 TCP 요청·재전송의 계약은 [ADR 0010](0010-record-device-integration.md)을 따른다. 폴더 검사가 슬롯을 점유한 동안 새 TCP 입력은 기존 포화 응답을 받는다. 저장 중 오류는 재시도 상태로 보고하고, 취소와 미처리를 집계한다. 강제 종료된 작업을 완료로 표시하지 않는다. S11 동결의 설정, 등록 TCP 설정과 평가 근거는 [ADR 0011](0011-algorithm-integration-evaluation.md)을 따른다.

실제 MFC 폴더 선택, 데이터 전체 경로·해시 대조, 실제 MySQL 이력과 판정 필터, 재연결, 중지 및 재시작을 검증한다.
