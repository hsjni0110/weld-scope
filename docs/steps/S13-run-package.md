# WeldScope 폴더 검사 실행

Windows에서 검수 ZIP을 쓰기 가능한 새 폴더에 푼다. VC++ x64 런타임과 MySQL Community 8.4.13 Windows ZIP 설치본이 필요하다. 저장소 아래 검수 폴더에서는 기존 `.tools`의 MySQL을 찾는다. 다른 위치에서는 Windows 환경 변수 `WELDSCOPE_MYSQL_HOME`에 MySQL 설치 폴더를 한 번 지정한다.

1. **WeldScope-Start.cmd**를 더블클릭한다. 실습용 서버는 이 PC의 루프백 주소에서만 동작하며 앱을 닫으면 종료된다.
2. **폴더 검사 → 폴더 선택**에서 풀어 놓은 데이터셋의 루트 폴더를 고른다. 하위 폴더를 포함한 발견 수를 확인한 뒤 **검사 시작**을 누른다.
3. **정상**, **불량**, **검토 필요**, **처리 오류** 중 필요한 판정을 눌러 결과를 확인한다. 행을 선택하고 상세를 열면 판정 사유와 영상이 표시된다.
4. 이전 실행은 폴더 검사 화면의 검사 이력에서 선택한다. ZIP의 샘플과 공개 데이터의 출처는 `THIRD-PARTY-NOTICES.md`에 있다.
