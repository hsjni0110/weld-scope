# S01 개발 환경

상태: 사용자 완료 확인. 2026-11-17 사용자가 “S01까지 진행했어. S02 진행해”라고 확인했다. 아래 설치 전 점검과 체크리스트는 2026-11-16 당시 기록이며 현재 미완료 작업 지시가 아니다. 실제 버전, 빌드·실행 로그와 이미지 표시 증거는 이 문서에 아직 보완되지 않았으며 에이전트가 재검증하지 않았다.

## 목표와 범위

UTM의 Windows 11 ARM에서 Visual Studio로 MFC 창을 빌드하고 OpenCV 이미지 한 장을 표시한다. 제품 검사 기능, MySQL, TCP는 이번 단계에서 구현하지 않는다. 관련 결정은 [ADR 0002](../adr/0002-development-environment.md)이다.

## 확인 결과

2026-11-16에 프로젝트 경로에서 `df -h .`를 실행했다. 가용 공간은 약 62GiB다. 당시 측정값이며 이후 정리 작업을 반영한 현재 가용 공간은 재확인이 필요하다. UTM은 이미 설치되어 있다는 사용자 확인을 받았으며, 버전과 실행 상태는 아직 확인하지 않았다. `/Volumes`에 외장 데이터 디스크는 확인되지 않았다.

Windows, Visual Studio, SDK, OpenCV 빌드와 다운로드 파일을 함께 보관할 공간이 필요하다. 내부 디스크에 약 100GB 이상의 여유를 확보하거나 여유 있는 외장 SSD에 가상머신을 배치하는 방향을 제안한다. 100GB는 공식 최소 사양이 아니라 개발용 여유 권장치다. Claude·Notion 로컬 앱 데이터와 사용자 캐시는 휴지통으로 이동했다. 휴지통 이동만으로 확보된 공간을 계산하지 않으며, 가상머신 생성 전에 실제 가용 공간을 다시 확인한다.

## 진행 순서와 검수

| 순서 | 작업 | 사용자 조작과 기록 값 | 눈으로 확인할 결과 |
|---|---|---|---|
| 1 | 저장 위치 결정 | 내부 여유 공간 또는 외장 SSD 경로. 이 문서에 기록 | 실제 가용 공간 |
| 2 | 기존 UTM 확인 | 설치된 UTM 실행, 버전과 Windows ARM 구성 방식 확인 | UTM 시작 화면 |
| 3 | Windows ARM 설치 | ARM64 이미지, VM 생성, Windows 초기 설정. VM 경로와 Windows 버전 기록 | Windows 바탕화면 |
| 4 | Visual Studio 구성 | C++ 데스크톱 개발, MFC, Windows SDK. 실제 설치 버전과 대상 아키텍처 기록 | MFC 프로젝트 빌드 및 빈 창 실행 |
| 5 | OpenCV 이미지 표시 | 같은 대상 아키텍처의 OpenCV 연결. 필요한 디자인 스킬 적용 후 최소 뷰어 작성 | MFC 창의 테스트 이미지 |
| 6 | 재실행 검수 | 실행 절차, 빌드 로그, 실제 관찰 결과 기록 | 종료 후 재실행한 같은 이미지 |

계정 비밀번호, 관리자 비밀번호, 복구 키 등은 문서나 스크립트로 수집하지 않고 해당 설치 화면에서 사용자가 직접 입력한다. 버전과 경로만 공개 설정으로 기록한다. 각 설치 화면의 실제 상태를 확인하고 다음 조작을 구체화한다.

## 현재 실행할 설치 준비

1. 설치된 UTM을 실행하고 실제 버전을 기록한다.
2. 가상머신 저장 위치와 현재 여유 공간을 확인한다.
3. 해당 UTM 버전의 공식 Windows 안내를 확인하고 Windows 11 ARM 설치 방식과 필요한 게스트 도구를 정한다.
4. Windows ARM64 이미지와 가상머신 구성에 필요한 자원을 확인한다. 메모리와 CPU의 초기 제안은 ADR 0002를 따른다.
5. 사용자가 설치 준비를 검수한 뒤 Windows 설치를 진행한다.

UTM 설치는 사용자 확인 사항이며 실제 실행이나 Windows 설치를 완료한 상태는 아니다. 저장 위치가 정해지기 전에는 Windows ISO와 가상 디스크의 대용량 준비를 시작하지 않는다.

- [ ] Visual Studio의 MFC 빌드와 창 실행
- [ ] 동일 아키텍처의 OpenCV 연결과 이미지 표시

설치 안내 작성은 S01 완료가 아니다. ARM64 또는 x64 빌드 선택은 설치 가능한 도구와 의존성 확인 후 결정하고, 장기 아키텍처 선택이 되면 별도 ADR로 검수한다.
