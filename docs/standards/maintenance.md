# 문서와 코드 관리

## 단일 기준

요구사항은 PRD, 실행 순서와 상태는 ROADMAP.md, 중요 결정은 ADR, 작업 규칙은 standards 문서가 기준이다. AGENTS.md는 참조 조건과 필수 규칙만 유지한다. 상세 내용을 여러 문서에 복사하지 않는다.

설정 파일에서 바로 확인할 수 있는 버전·명령·목록을 여러 문서에 수동으로 중복 유지하지 않는다. 실행 예제가 필요하면 실제로 검증한 명령과 해당 환경을 기록한다.

## 낡은 내용 제거

변경으로 유효하지 않게 된 문서, 코드, 주석, 예제, fixture, 설정은 같은 작업에서 항상 갱신하거나 삭제한다. 예전 구현을 주석 처리해서 남기거나 old, backup, v2 파일을 병렬로 유지하지 않는다. 필요하면 현재 유효한 내용만 기준 문서에 통합하고 기존 파일을 삭제한다.

삭제 전 실제 참조와 사용자 작업 여부를 확인한다. 사용자가 작성한 내용이나 외부 데이터인지 불분명한 파일은 낡았다고 추정해 삭제하지 않는다. 확인되지 않은 항목은 이름과 판단에 필요한 근거를 검수에서 알린다.

이전 ADR이 대체될 때 현재 결정에 필요한 맥락과 변경 이유를 새 ADR로 옮기고 기존 ADR을 삭제한다. 모든 링크와 ADR 목록을 갱신하고 번호를 재사용하지 않는다. Git을 사용하는 시점부터 과거 내용은 Git 이력으로 추적한다. 아직 Git이 없으므로 단순 문서 이동 과정에서 고유한 결정 근거가 사라지지 않게 한다.

완료된 단계 기록은 유효한 재현·검수 증거만 유지한다. 더 이상 실행되지 않는 절차와 미래 작업 지시는 제거한다. 과거 측정은 실행 당시의 버전과 환경이 표시된 증거로 유지할 수 있지만 현재 성능으로 제시하지 않는다.

## 완료 점검

- 변경한 기능과 PRD·로드맵·관련 ADR의 의미가 일치한다.
- 낡은 구현, 중복 문서, 깨진 참조, 불필요한 임시 파일이 없다.
- 각 요구사항에는 현재 기준 문서가 하나 있다.
- 시연 절차가 실제 실행 결과와 일치한다.
- 미검증 항목과 사용자 검수 상태가 명확하다.
- 중요한 결정을 코드에만 숨기지 않았다.
- 사용자 요청 범위 밖의 파일은 보존했다.

새 문서는 필요한 시점에 만든다. 긴 작업 기록을 AGENTS.md에 계속 누적하지 않는다.
