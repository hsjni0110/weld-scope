# S04 기준 설정

`baseline.json`은 학습하지 않은 전역 밝기 기준이다. 흑백 값이 128 이하인 픽셀의 비율이 0.5 이상이면 FAIL이다. 두 등호 경계를 C++ 검사로 검증한다.

2026-11-18 전체 train 실행 전에 고정했다. S02의 16개 고정 train 샘플을 라벨 구분 없이 합친 흑백 분포의 25/50/75% 지점은 74/95/125였다. 128은 8비트 밝기 범위의 중간값이며 0.5는 전체 면적의 절반이다. 성능을 최대화한 값이 아니라 누구나 해석할 수 있는 최초 기준이다. 이 선택은 밝은 용접부 주변의 어두운 배경도 후보로 잡는 한계가 있다.

validation/test는 설정 선택에 사용하지 않는다. 설정이 좋지 않으면 실패 사례와 함께 보고하고 S07에서 개선한다. 변경 시 새 출력 디렉터리를 사용하며 파일 SHA-256으로 실행을 구분한다. score는 확률이나 실제 결함 면적이 아니다.
